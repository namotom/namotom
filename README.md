# 👋 Hi, I’m @namotom

I am a Designer Generalist and problem solver who likes to build systems, tools, and cohesive digital ecosystems. By night, I’m usually breaking down game economies, messing with level design algorithms, or acting as a self-proclaimed watermelon connoisseur.
